PrimePath Diagnostics website starter
====================================

Files:
- index.html: website structure and text
- style.css: design and responsive layout
- script.js: mobile menu and WhatsApp booking form

To preview:
1. Extract this ZIP.
2. Open index.html in a browser.

Before publishing, review:
- Phone and WhatsApp number
- Location wording
- Test list and actual availability
- Lab hours
- Whether home collection is free for all areas
- Replace the PP placeholder mark with the official logo if available

This starter uses a WhatsApp booking form; it does not collect or store patient information on a server.
